## Experimental Devices/Environments

To add experimental support for `Intel` or `AMD` devices, this can be done with a few simple setps

1. Edit `Settings.json`
2. Add Vendor name to `Vendors` key (Nvidia, Intel or AMD)
3. Start Amuse, Settings -> Environment -> Import
4. Import the `environment.json` for the specified vendor
